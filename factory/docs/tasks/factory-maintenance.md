Status: planning
Branch: game-factory
Worktree: .worktrees/game-factory
Goal: Once a day, a maintenance branch fixes one slow spot, quality issue or stale doc and reaches the committee like any task.
Mode: hands-off

## Context

- Part of the [game factory](game-factory.md). Its Design and Plan cover this part, so each contract has one home.
- Once a day, Sonnet 5.5 looks for one of: slow spots in the game or tests, code quality issues, or stale docs.
- It fixes one on a branch that goes through deploy and approval like any task.
- Perf checks stay a manual job on the user's Mac, since the server has no GPU.
